## Reproduce offline

After installing [the Python dependencies](../python/README.md), run from the repository root:

```bash
python3 scripts/check_public.py
python3 -m unittest discover -s checks -p 'test_*.py'
node --test checks/*.test.mjs
(cd python && python -m pytest -q)
python scripts/compare_demos.py
```

To regenerate synthetic output evidence and the local validation record:

```bash
node scripts/demo_n8n.mjs > assets/evidence/n8n-fixture-run.json
python scripts/demo_python.py > assets/evidence/python-fixture-run.json
python scripts/record_validation.py
```

These commands do not intentionally contact production services. Python dependencies must already be installed; installing packages requires network access. CI also installs dependencies.

## Pending gates before live use

1. **Full n8n import and manual execution:** local release work had no running Docker daemon and no installed n8n engine. We did not connect to the production VPS, start services or claim an import pass. Import the seven exports into a dedicated compatible instance, record the runtime/community-node versions and rebind children/credentials.
2. **Live integration:** use dedicated test tables to verify feed access, field serialization, all three business entries, summary/metrics behavior and stable reruns. Capture the final Catch visibility result and action counts.
3. **Concurrency and recovery:** test real simultaneous Entry executions and SQLite uncertainty/recovery behavior in the actual runner topology.
4. **Python benchmark parity:** structured benchmark fields and full-flow equivalence are not implemented or accepted.
5. **Actual product visuals:** no verified historical n8n UI or live-output screenshot is included. The supplied graphics are explicitly architecture/fixture illustrations. Add a safely redacted real capture later; do not relabel the current graphics.

None of these pending gates is replaced by a green offline CI badge. The repository is publishable as a scoped engineering portfolio; full live readiness is a separate acceptance result.
