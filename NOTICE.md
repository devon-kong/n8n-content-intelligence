# Publication scope

This public repository is an engineering portfolio containing sanitized workflow definitions, a companion Python implementation, synthetic examples and validation materials.

- Credentials, private environment identifiers, pinned execution data, databases, raw logs and internal handoffs are excluded.
- The original private development history is not imported. Workflow source hashes in the manifest identify selected inputs without publishing their operational context.
- Real services and dependencies are not bundled. Their licenses, account requirements and usage terms apply independently.
- A project-wide reuse license has not yet been selected. Public visibility is for inspection and does not itself grant a blanket reuse license. No license over n8n, upstream services or other dependencies is asserted.
- The publication checks cover explicit patterns and known-source identifiers. They are bounded checks, not a guarantee that every conceivable secret can be detected. Binary graphics also receive separate visual inspection.

For the precise verified scope and pending live gates, see [validation](docs/validation.md).
